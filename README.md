# Profil CAD – Kurulum

Profil kesitlerini DWG/DXF'ten açıp düzenlemek için 2B çizim programı (Windows 10/11).

**İndir:** [ProfilCAD-Setup.exe](https://github.com/har96un/ProfilCAD-Setup/releases/latest/download/ProfilCAD-Setup.exe)

Dosyayı indirip çalıştırın. Kurulum .NET gerektirmez ve yönetici yetkisi istemeden kullanıcı klasörüne kurulabilir.
Windows "bilinmeyen yayıncı" uyarısı verirse **Ek bilgi → Yine de çalıştır** seçin.
